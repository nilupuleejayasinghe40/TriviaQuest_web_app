# TriviaQuest - ICT Trivia Quiz Website

## Project Overview
TriviaQuest is a simple web-based trivia quiz application focused on ICT and computer basics.  
The project is built using **HTML, CSS, JavaScript, and Bootstrap**.  
It allows users to sign up, log in, and test their knowledge through multiple quiz questions.

This project was developed as an academic project to demonstrate front-end web development concepts.

---

## Features

- User Signup and Login (Client-side authentication)
- Interactive quiz system
- Multiple difficulty levels (Easy, Medium, Hard)
- 30-second timer for each question
- Score calculation
- Leaderboard system
- Dark mode / Light mode theme toggle
- Responsive design using Bootstrap

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap

## How to Run the Project

1. Download or clone the repository

git clone https://github.com/nilupuleejayasinghe40/TriviaQuest_web_app

2. Open the project folder

3. Open **index.html** in a web browser.

No installation or server is required.

---

## How the Quiz Works

- Users must create an account or login
- Quiz questions are loaded using JavaScript
- Each question has a timer
- The final score is calculated and saved in the browser using **localStorage**
